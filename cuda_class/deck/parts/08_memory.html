O modelo de memória

main.py measure → parts/kernel.json (resources: constant_bytes)

Quanto mais perto do thread, mais rápida e menor. O EP4 usa três: o fóton vive em registradores, a estrela em memória constante (todos os threads leem os mesmos números), a imagem em memória global.

Diferença dentro do ruído: a estrela tem 18 KB e cabe nas caches. Mantemos a constante porque ela diz o que o dado é: só leitura, igual para todos.

A imagem é um histograma de fótons

o jeito do guia (histogramas pequenos)

o nosso (1,26 bilhão de pixels)


__device__ void count_photon_atomic(
        PixelCount *counts, unsigned long long pixel) {
    atomicAdd(&counts[pixel], 1u);   // direto na global
}
  • 1024² × 300 quadros × 4 observadores = 1,26·10⁹ contagens: 5 GB não cabem em 100 KB
  • com bilhões de endereços, dois fótons quase nunca disputam o mesmo pixel

E as contagens são inteiras: somadas em qualquer ordem, dão o mesmo número. Atômicos em ponto flutuante dependem da ordem (guia 5.6.8). É uma das razões de a imagem sair bit a bit.
